# Django expense tracker

Record daily expenses, edit entries and inspect spending by category or time period. The dashboard shows totals for the past 7, 30 and 365 days alongside charts.

## Explore the dashboard

- [Expense model](myapp/models.py) and [entry form](myapp/forms.py)
- [Dashboard queries and edit handlers](myapp/views.py)
- [Dashboard template](myapp/templates/myapp/index.html) with the expense table and charts
